# 调研流程清晰化实施计划

## 目标与范围
根据用户确认的诊断，先交付无需迁移数据的第一轮改进：首屏价值说明、任务导向命名、按资料推荐下一步、已有报告优先展示、新旧关键词报告状态统一。保持三入口和旧 URL，避免重排全部功能带来回归。关注与候选拆分、跨市场证据字段和行动卡生成留待后续，当前不改变数据或模型提示词。

## 架构与约束
Python 3.10+ 标准库、原生前端；不新增运行依赖，不调用真实采集或模型。旧报告可读，原文与证据快照保留。用独立分支提 PR，不部署。
