# 下拉词采集与关键词清洗

依据：知识库《用七步搜索法建立长尾关键词库》与《富贵·小红书下拉词数据清洗》；现有 clean 提示词已包含七步，复用原接口，不复制新分析引擎。

- 采集路径：大词 → 内容提炼种子词 → 下拉联想 → 逐轮下钻 → 人工核对 → 清洗。
- 清洗路径：去重 → 无效词筛查 → 5W1H → 搜索意图 → A1–A5 → 情绪 → 归一主题。
- 页面呈现四区结果，独立调用 clean 模块，旧报告保留。
- 词频、记录数不当成人数或搜索量；原始量、轮次缺失不推断。
- 原词不删除；排除标记尚未自动限制人群模块取样。当前是前端流程与已有清洗能力的连接，非全流程自动运行。

验证：11 组 JavaScript 测试通过。真实浏览器点击清洗入口后，七步与独立清洗按钮可见；628px 页面无整体横向溢出。本机只读 HTTP 与磁盘静态文件匹配。无第三方采集/模型请求。
