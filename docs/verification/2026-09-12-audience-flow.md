# 拿词后的人群策略前端

## 本次纠偏

用户要的是拿词后的人群策略，而非竞品选品。参考方案的消费者任务视角，结合用户知识库里的千机塔统一八层，重新组织现有报告的阅读和判断顺序。

主导航：关键词整理 → 人群与场景 → 千机塔洞察 → 人群策略 → 内容与验证。

## 实现边界

- 新增四个页面，复用同一份已保存报告；人群选择贯穿后续页面。
- 采集与原始资料、竞品参考、报告与导出保留在辅助入口。
- 旧报告不补造隐秘欲望，旧深层情感和价值观在完整报告中保留。
- 项目级选题和综合判断未自动关联到具体人群，页面明确提醒核对。
- 无新模型调用、无采集、无业务数据改写、无上线。

## 验证

- `for f in tests/*.js; do node "$f" || exit 1; done`：10 组通过。
- 新测试覆盖四页面、八层名称、同人群切换、原文引用、旧数据提示、转义、空状态与零模型调用。
- 内置浏览器检查五步导航、辅助按钮、旧报告正文；628px 视口无页面横向溢出。
- 页面原有示例保留，不把演示报告充当市场结论。
- 本机 HTTP 对照临时演示数据目录校验服务标识、项目列表/原文及四个修改的静态资源，均通过。默认 `check_project.py --url` 只认仓库默认数据目录，因此不适用于临时演示目录；本轮改用显式临时目录校验，未更改正式数据。
- `scripts/check_project.py` 本地只读初始化检查通过。
