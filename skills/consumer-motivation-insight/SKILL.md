# 消费动机洞察 · 远见本地适配

本方法用于分析当前项目资料，不包含远程检索客户端。

网站调用 `segments` 人群策略模块时，自动加载 [分析规则](analysis.md)。
不需要把文件装入全局 Skill 目录，也不覆盖现有小红书采集 Skill。

本方法从项目提供的资料分析，保持原始证据编号，不伪装已访问远端数据库。
原始运行脚本、服务配置和数据库没有公开；本项目不尝试调用不存在的 scripts/main.py，不宣称具备原数据集访问能力。
